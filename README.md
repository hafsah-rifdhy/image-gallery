# 🖼️ Image Gallery

A responsive **Image Gallery** web project built using **HTML, CSS, and JavaScript**. It displays images in an organized grid with interactive features such as filtering, image preview, and navigation.

## ✨ Features

- 📸 Responsive image grid
- 🔍 Full-screen image preview
- ⬅️ Previous image navigation
- ➡️ Next image navigation
- 🏷️ Filter images by category
- 🖱️ Image hover effects
- ⌨️ Keyboard navigation
- ❌ Close preview using the Escape key
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
